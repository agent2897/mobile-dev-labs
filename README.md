# Розробка програмних додатків для мобільних пристроїв

Миленко Юрій, група 401

| № | Тема | Папка |
|---|------|-------|
| 1 | Таймер Помодоро | [lab1-pomodoro](lab1-pomodoro) |
| 2 | Браузер фільмів | [lab2-movies](lab2-movies) |
| 3 | Погода (Redux, вкладки) | [lab3-weather](lab3-weather) |
| 4 | Трекер витрат (Flutter) | [lab4-expenses](lab4-expenses) |
| 5 | Трекер звичок (Kotlin, нативно) | [lab5-habits](lab5-habits) |
| 6 | Курси валют НБУ (.NET MAUI) | [lab6-currency](lab6-currency) |

Запуск ЛР1–3: `cd labN-...`, `npm install`, `npx expo start`, відсканувати QR-код в Expo Go.

Запуск ЛР4: `cd lab4-expenses`, `flutter pub get`, `flutter run`.

Запуск ЛР5: відкрити `lab5-habits` в Android Studio або `gradlew installDebug` з підключеним пристроєм.

Запуск ЛР6: `cd lab6-currency`, `dotnet build -t:Run -f net9.0-android` з підключеним пристроєм.
